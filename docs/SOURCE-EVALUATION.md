운영 상태를 바꾸지 않고 1회 실측해 비교한다.

## 배경

- 같은 날 매체 서브도메인 중복을 수정했다(`bdddc52`). 기존 14건은 다음 수집 때 13건·10개 매체로 합쳐진다.

## 결정

두 수집원은 겹침이 적고 서로 보완적이므로 둘 다 쓴다(`tavily_feeds`).
Tavily는 기간 전체와 소규모 매체를, 사이트맵/RSS는 주요 매체의 당일 기사와 언론사 제공 발행일을 맡는다.

- 수집원:
  - Tavily 검색어는 5개(하루 5크레딧)다.
  - 사이트맵·RSS는 실측에서 제목·날짜를 확인한 17개 주소를 고정 목록으로 쓴다. 문서마다 해당 호스트의 robots.txt를 확인한다.
- 날짜와 중복:
  - 같은 URL은 언론사 제공 날짜를 우선한다.
  - 공개 날짜 근거는 `reported_publication_date`이며 "일부는 갱신일일 수 있음"을 표시한다.
  - 같은 매체·같은 제목은 날짜가 달라도 한 기사로 센다.
- 제외: 회사 사이트·보도자료 배포처는 `excluded_publishers`로 뺀다.
- 이전 수집분: Codex 수집분(원문 확인 발행일)은 30일 안에서 출처와 최초 확인일을 그대로 두고 유지한다.
- 롤백: Codex 웹 검색·GDELT 경로는 설정으로 되돌릴 수 있게 남긴다.
