## 수집 경로 검증

### Google News RSS — 기본 경로 제외

일회성 연결 확인에서는 여러 매체의 RSS 검색 결과가 반환됐다. 그러나 현재
`news.google.com/robots.txt`는 `/rss/`를 허용하지 않고, Google News 이용 안내에도
자동 수집·검색 결과 재표시에 제약이 있어 기본 수집기로 채택하지 않았다.
RSS가 반환된다는 이유로 접근·재사용이 보장된다고 설명하지 않는다.
해당 결과를 샘플 데이터로 채택하거나 공개하지 않았다. 반복 접근·차단 우회는 하지 않는다.

### GDELT DOC API — 구현 대상, 안정성과 커버리지 검증 필요

공식 설명은 데이터의 분석·재배포를 허용하고 GDELT 인용과 링크를 요구한다.
이는 원문 언론사의 기사 전문·사진까지 재사용할 권리를 뜻하지 않는다.

- 넓은 `Hyosung` 검색과 한국어 조건 검색에서 HTTP 429가 반복됐다.
- `"Cho Hyun-joon"` 검색은 HTTP 200과 기사 1건을 반환했다. 제목에는 인물이
  없어 현재의 보수적인 제목 기반 선정 조건을 충족하지 않는다.
- `"Hyosung"`, 최근 7일·최대 30건의 단건 검증에서 HTTP 200, 기사 5건·매체
  도메인 5개를 확인했다. 제목에 인물과 회사가 함께 있는 것은 1건이었다.
- 회사 일반 기사·다른 기업 기사·본문에서만 검색어가 일치한 기사를 대상 인물의
  확정 관련 기사로 임의 확대하지 않는다. 현재 자료는 제목 기반 분석만 가능하다.
- 실제 수집기 반복 실행에서는 429 실패도 확인했다. 이를 '기사 없음'이나
  '실제 다매체 대상 기사 확보 완료'로 기록하지 않는다.
- 입력 기간·상한을 줄이고 문서화된 상대 기간 API를 사용하도록 기본값을 조정했다.
  IP 교체·프록시·브라우저 위장으로 호출 제한을 회피하지 않는다.

현재 **수집기 구현·격리 테스트는 완료**했지만, 실제 다매체 대상 기사 확보와 안정성
검증은 별도다. 충분한 실자료 확보 전에 자동 수집 전체 완료나 공개 샘플 완성을 주장하지 않는다.
사용자에게 기사 목록 수동 입력을 요구하거나 임의의 기사를 만들어 이 단계를 대체하지 않는다.
